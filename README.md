# 🔍 Perplexity Explorer

**Explore how language models understand text through token probabilities, perplexity, and next-token predictions.**



Perplexity Explorer is a beginner-friendly educational web application that demonstrates how a language model assigns probabilities to individual tokens in a sentence and uses those probabilities to calculate perplexity.



Built using HTML, CSS, and vanilla JavaScript, the application runs a real causal language model directly in the browser using Hugging Face Transformers.js.

## ✨ Features

### 📝 1. Sentence Analysis

- Enter your own sentence or choose from predefined examples.
- Analyze sentences such as `I love Python` and `The capital of France is Paris`.
- Load the language model on the first analysis request.
- Reuse the loaded model for subsequent calculations.

### 📊 2. Token Probability Analysis

- View the individual tokens generated by the tokenizer.
- Inspect the probability assigned to each actual token.
- View the reciprocal probability, `1/P`, for every token.
- Display token boundaries clearly, with spaces represented by `␣`.

### 🧮 3. Perplexity Calculator

- Calculate perplexity using token probabilities from the real model.
- Display the token count and reciprocal-probability product.
- Use logarithms to calculate perplexity reliably for longer sentences.
- Understand how individual token probabilities contribute to the final result.

### 🔮 4. Next-Token Predictions

- Display the model's eight most probable next tokens.
- Visualize their probabilities using horizontal bars.
- Highlight the highest-probability prediction.
- Explore how a language model predicts possible continuations of a sentence.

### 🧪 5. Interactive Manual Simulator

Experiment with hypothetical token probabilities without loading the language model.

- Add and remove token rows.
- Edit token names and probabilities.
- Recalculate perplexity instantly.
- Try built-in presets:
  - **I love Python:** probabilities of `0.5`, `0.8`, and `0.2`.
  - **All 1/8:** eight tokens with probability `0.125` each.
  - **One surprising word:** probabilities of `0.9`, `0.9`, `0.9`, and `0.01`.

> **Note:** Manual simulator results are hypothetical and are not generated by the language model.

### 🎨 6. Clean and Responsive Interface

- Modern, light-themed interface.
- Rounded cards and blue-purple accents.
- Responsive layouts for desktop, tablet, and mobile.
- Loading indicators and error messages.
- Beginner-friendly explanations of the underlying mathematics.

##

Perplexity measures how well a language model predicts a sequence of tokens. Lower perplexity generally indicates that the model assigned higher probabilities to the observed tokens.





## 🚀 Getting Started

### Prerequisites

You need:

- A modern browser that supports JavaScript ES modules.
- An internet connection to download Transformers.js and the model files.
- A local HTTP server, such as the VS Code Live Server extension.

### Installation

**1. Clone the repository**
```
git clone https://github.com/YOUR-USERNAME/Perplexity-Explorer.git
```

Replace `YOUR-USERNAME` with your GitHub username.



**2. Open the project directory**
```
cd Perplexity-Explorer
```

**3. Run the application**



Open the folder in Visual Studio Code and start the `index.html` file using the Live Server extension.



Alternatively, if Python is installed, run:
```
python3 -m http.server 8000
```

Then open:



[http://localhost:8000](http://localhost:8000)



**4. Analyze a sentence**

1. Enter a sentence or select a sample.
2. Click **Calculate perplexity**.
3. Wait for the model to download and initialize on the first run.
4. Explore the token probabilities, perplexity calculation, and next-token predictions.
5. Scroll to the manual simulator to experiment with your own probabilities.

## ⚙️ How It Works

1. **Tokenization:** The input sentence is converted into token IDs.
2. **Context preparation:** The application prepends the configured token ID `50256`.
3. **Model inference:** DistilGPT-2 processes the input sequence and produces logits.
4. **Probability calculation:** Stable softmax converts logits into probabilities, and the probability of each actual token is extracted from the preceding position.
5. **Perplexity calculation:** The application computes the average negative log-probability and exponentiates it.
6. **Next-token prediction:** The logits at the final input position are used to identify the eight most probable next tokens.
7. **Manual simulation:** A separate calculator demonstrates the same perplexity mathematics using user-entered probabilities.

The context marker is excluded from the sentence token count.

## 🔒 Privacy and Limitations

- No custom backend or API key is required.
- Model inference is performed in the browser.
- The model and JavaScript library must be downloaded from external hosting services.
- The first model load may take time and use significant memory.
- Browser compatibility, network connectivity, and available memory can affect performance.
- The model's predictions are probabilistic and should not be interpreted as guaranteed continuations.
- Perplexity values depend on the model, tokenizer, tokenization, and calculation method.

The application displays an error rather than substituting fabricated probabilities if model initialization or inference fails.
