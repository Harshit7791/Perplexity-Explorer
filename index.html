05 Documentation & Theoretical Guide

In-depth reference on language model probability theory, causal inference, and mathematical derivation.

What is Perplexity?

In natural language processing, Perplexity ($PP$) is the standard metric used to evaluate how well a probabilistic language model predicts a sample of text. Intuitively, perplexity answers the question:

"On average, how many equally likely words was the model confused between at each step?"

If a model predicts a sequence with a perplexity of 8, it means the model was as uncertain as if it had to choose uniformly at random among 8 possible words for each position. A perplexity of 1.0 represents absolute certainty ($P = 1.0$) with zero surprise.

Surprise and the Reciprocal Probability ($1/P$)

The value $1/P$ is the branching factor or surprise of an individual token:

  • If the model assigns $P = 0.5$, then $1/P = 2$ (as difficult as a 2-sided coin flip).
  • If the model assigns $P = 0.125$, then $1/P = 8$ (as difficult as rolling an 8-sided die).
  • If the model assigns $P = 0.001$, then $1/P = 1000$ (highly unexpected, high surprise).

Step-by-Step Mathematical Formulation

For a sentence composed of $N$ tokens $(w_1, w_2, \dots, w_N)$, the joint probability is decomposed via the chain rule:

P(w₁, w₂, …, w_N) = ∏ [i=1 to N] P(wᵢ | w₁, …, w_{i-1})

1. Geometric Mean of Reciprocals:

Perplexity is defined as the reciprocal of the geometric mean of token probabilities:

Perplexity = ( ∏ [i=1 to N] (1 / P(wᵢ | context)) ) ^ (1 / N)

2. Logarithmic Formulation (Cross-Entropy):

Direct multiplication of probabilities causes floating-point underflow for sentences longer than a few words. Instead, computations are performed in log-space:

ln(PP) = - (1 / N) × ∑ [i=1 to N] ln( P(wᵢ | context) ) PP = exp( - (1 / N) × ∑ [i=1 to N] ln( P(wᵢ | context) ) )

Notice that $- (1 / N) \sum \ln P(w_i)$ is exactly the average cross-entropy loss ($\mathcal{L}$). Thus, Perplexity is simply the exponential of cross-entropy:

PP = exp( CrossEntropyLoss )

Numerically Stable Softmax

Given the unnormalized logit vector $z \in \mathbb{R}^V$ from the model, standard softmax computes $e^{z_i} / \sum e^{z_j}$. If any logit exceeds ~709, standard IEEE-754 floating-point arithmetic overflows to Infinity. To avoid this, we subtract $\max(z)$:

P(wᵢ) = exp(zᵢ − max(z)) / ∑ [v in Vocab] exp(zᵥ − max(z))

This is mathematically identical but guaranteed to never overflow.

Why Context Marker 50256 (<|endoftext|>) is Required

DistilGPT-2 is a causal autoregressive model. Each position $t$ predicts the token at position $t+1$:

Sequence: [Token 0] ──predicts──> [Token 1] ──predicts──> [Token 2] ...

When evaluating the probability of the first sentence token (e.g. "I" in "I love Python"), what precedes it? Without a preceding token, the model cannot predict the first word!

Prepending token ID 50256 (the standard GPT-2 <|endoftext|> token) provides the unconditioned start context:

  • Position 0 (Marker 50256) logits predict Token 1 ("I").
  • Position 1 ("I") logits predict Token 2 (" love").
  • Position 2 (" love") logits predict Token 3 (" Python").
  • Position 3 (" Python") logits predict the Next token (Section 3).

Because the marker is prompt context rather than an actual word written by the user, it is strictly excluded from the token count $N$ and the reciprocal product.

1.0 – 8.0 Very High Common idioms, highly frequent phrases, natural syntax (e.g. "The capital of France is Paris").

50.0 – 150.0 Low Technical terminology, unexpected topics, or unconventional grammar.
> 150.0 Very Low / Surprising Grammatically incorrect, scrambled word order (e.g. "Python love I"), or random text.
